# Phase 1 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> Sources: 01-CONTEXT.md (D-01..D-18, locked), 01-RESEARCH.md (tested tokens, contrast remap, legibility budget), FEATURES.md §UX Conventions, REQUIREMENTS.md. Values marked **[default]** were chosen here under "Claude's Discretion" to fit the locked decisions.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (vanilla HTML/CSS/JS, single `index.html`; not React, so the shadcn gate does not apply) |
| Preset | not applicable |
| Component library | none (native `<form>`, `<input type="range">`, `<input type="number">`, radio `<fieldset>`, `<table>`) |
| Icon library | none. Text and Unicode only (`×`, `÷`, `≥`, `·`, `−`, `*`). No icon fonts, no SVG sprites, no external requests (DEPLOY-01, CSP `default-src 'none'`) |
| Font (prose) | `--font-prose: Georgia, "Palatino Linotype", Palatino, "Book Antiqua", serif` (D-05) |
| Font (numbers) | `--font-num: system-ui, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif` with `font-variant-numeric: tabular-nums` on every element that shows a number (D-07) |
| Theming | CSS custom properties on `:root`, redefined in `@media (prefers-color-scheme: dark)`. `color-scheme: light dark` on `:root` plus `<meta name="color-scheme" content="light dark">` so native controls follow the theme (D-06) |

## Spacing Scale

Declared values (multiples of 4). Implement as custom properties `--sp-1` .. `--sp-6`.

| Token | Value | Usage |
|-------|-------|-------|
| xs (`--sp-1`) | 4px | Label-to-hint gap, legend swatch-to-text gap, note-column left padding |
| sm (`--sp-2`) | 8px | Slider-to-number gap, label-to-control gap inside a control group, stat card internal row gap, legend padding-block |
| md (`--sp-3`) | 16px | Page inline padding (all widths), card padding, stat grid gap, control strip padding-block, legend item gap, row-gap of the control strip |
| lg (`--sp-4`) | 24px | Control strip padding-inline, column-gap between control groups, header padding-top |
| xl (`--sp-5`) | 32px | Vertical gap between page sections (header / strip / stats / table section / footer) |
| 2xl (`--sp-6`) | 48px | Space above the footer |
| 3xl | 64px | Not used in Phase 1 (reserved) |

**Component dimensions (all multiples of 4):**

| Element | Size |
|---------|------|
| Control height (number inputs, die segments) | 40px |
| Number input width (AC, attack bonus, damage bonus) | 80px |
| AC range slider width | 192px base; `flex: 1 1 192px` so it grows on narrow screens |
| Die segment | 48px wide × 40px tall; five joined segments = 240px |
| Border radius | 4px (inputs, segments, legend swatches), 8px (control strip, stat cards, panels). Table cells: 0 |
| Stat card min width | 160px (`grid-template-columns: repeat(auto-fit, minmax(10rem, 1fr))`) |
| Page max width | 1440px (`90rem`), centered. Never capped below 1320px (D-02: Phase 2 needs ~1280px for three d12 tables) |
| Legend swatch | 40px × 28px (same as a wide-tier cell) |

**Outcome table size tiers.** Use container queries on `.table-wrap { container-type: inline-size }`, never viewport media queries. The wrapper is a block element whose width comes from the layout, never a shrink-to-fit element.

| Tier | Container width | `--cell` (col width) | Row height (all rows incl. header) | `--rowhead` | `--note` | Cell font | d12 table width |
|------|-----------------|----------------------|------------------------------------|-------------|----------|-----------|-----------------|
| wide (Phase 1 laptop) | ≥ 42rem (672px) | 40px | 28px | 44px | 128px | 14px | 12×40 + 44 + 128 = **652px** |
| mid (Phase 2 three-up at 1366px) | 25rem to < 42rem (400–671px) | 24px | 24px | 32px | 80px | 12px | 12×24 + 32 + 80 = **400px** |
| narrow (phones) | < 25rem | 20px | 20px | 24px | 64px | 12px | 12×20 + 24 + 64 = **328px** (fits a 360px viewport minus 2×16px) |

- Table uses `table-layout: fixed` with an explicit `width: calc(var(--rowhead) + var(--cols) * var(--cell) + var(--note))`. JS sets `--cols` to the die size. Never `width: auto`.
- Table is left-aligned inside the full-width wrapper (D-01, D-02). `.table-wrap` has `overflow-x: auto` as a last resort only; the page itself never scrolls horizontally.
- Phase 2 budget check: at 1366px, content ≈ 1317px; three mid-tier tracks = 3×400 + 2×16 gap = 1232px. Fits.
- Executor eyeballs d12 at 1366px and at 360px in both color schemes once (tiers are a tuned default, RESEARCH.md A7).

**Exceptions:**
- Stroke widths are not spacing tokens: 1px (hairlines, input borders, card borders), 2px (focus ring, crit-row rule), 3px (the "hits on N+" threshold rule and the focal stat card top border, RESEARCH.md Pattern 6).
- Miss-cell hatch pattern: 4px band + 1px line (`repeating-linear-gradient(135deg, …)`). A texture, not layout spacing.
- Table cells have 0 inline padding (text centered in fixed-width columns); the note column has 4px left padding.

## Typography

Exactly **4 sizes** (12, 14, 16, 28) and **2 weights** (400 regular, 700 bold). Georgia ships 400/700 natively, so 600 would be synthesized; 700 is the only emphasis weight.

| Role | Size | Weight | Line Height | Family | Used for |
|------|------|--------|-------------|--------|----------|
| Display | 28px | 700 | 1.2 | prose (h1), num (stat values) | Page title `h1`; the big value on each stat card |
| Heading | 16px | 700 | 1.2 | prose, `font-variant-caps: small-caps`, `letter-spacing: 0.04em` | Section `h2` ("Outcome table", "Value of the next +1") |
| Body | 16px | 400 | 1.5 | prose | Lede paragraph, marginal readout sentences, error banner, noscript; also the typed value inside number inputs (num family; 16px avoids iOS zoom-on-focus) |
| Label | 14px | 400 / 700 | 1.4 | prose for words, num for numbers | Control labels (700), die segment text (400, 700 when checked), stat card labels (400), table caption, legend text, crit footnote, self-test summary (700), wide-tier table cells (400) and headers (700) |
| Small | 12px | 400 / 700 | 1.4 | prose for words, num for numbers | Control range hints, stat card sub-lines, footer, self-test check list, mid/narrow-tier table cells (400) and headers (700) |

- Table rows use `line-height` equal to the tier row height (single line, vertically centered). All table text uses `--font-num` with tabular numerals, except the note column, which uses `--font-prose` italic.
- The `h1` is the only Display-size heading. No other heading sizes exist in Phase 1.
- Prose measure: lede and footnote `max-width: 72ch`.

## Color

Values from RESEARCH.md Pattern 6 (contrast computed OKLCH → sRGB → WCAG 2). Hex values are sRGB equivalents for reference; implement with the `oklch()` values. The status tokens (`--pass`, `--fail`) and `--line` are added here **[default]** and were contrast-checked in this session.

### Surface and ink (60 / 30 / 10)

| Role | Token | Light (parchment & ink) | Dark (candlelit) | Usage |
|------|-------|-------------------------|------------------|-------|
| Dominant (60%) | `--paper` | `oklch(0.96 0.022 85)` #f9f1e2 | `oklch(0.20 0.018 55)` #1d140e | Page background, table note column, number input fill, legend area |
| Secondary (30%) | `--surface` | `oklch(0.935 0.03 82)` #f4e8d4 | `oklch(0.245 0.022 55)` #291e16 | Control strip, stat cards, marginal card, self-test panel, error banner, unchecked die segments, table header row and row-header column |
| Accent (10%) | `--accent` | `oklch(0.48 0.10 70)` #81520a (5.95:1 on paper) | `oklch(0.80 0.11 80)` #e3b667 (9.6:1 on paper) | See reserved list below |
| Destructive | — | none | none | No destructive actions exist in Phase 1 |
| Text | `--ink` | `oklch(0.27 0.035 45)` #352118 (13.5:1 on paper) | `oklch(0.91 0.03 85)` #eae0cb (13.9:1) | All primary text, stat values |
| Muted text | `--ink-muted` | `oklch(0.45 0.03 55)` #635146 (6.2:1 on surface) | `oklch(0.76 0.03 75)` #bdaf9d (7.6:1 on surface) | Stat labels and sub-lines, range hints, caption, footnote, footer, `auto-miss` note, number input and die segment borders (≥ 3:1 non-text) |
| Rule | `--rule` | `oklch(0.30 0.04 40)` #3f271e | `oklch(0.85 0.05 80)` #dfcbaa | The 3px "hits on N+" threshold rule only |
| Hairline | `--line` | `color-mix(in oklch, var(--ink) 20%, var(--paper))` | same formula | 1px borders of control strip, cards, table grid lines, legend swatches, footer top border |

**Accent reserved for (exhaustive):**
1. Focus ring: `outline: 2px solid var(--accent); outline-offset: 2px` on `:focus-visible` for every control.
2. The checked die segment: background `--accent`, text `--paper` (5.95:1 light, 9.6:1 dark), weight 700.
3. AC range slider: `accent-color: var(--accent)`.
4. The crit row (d20 = 20): 2px inset bottom rule on every cell of the row (`box-shadow: inset 0 -2px 0 0 var(--accent)`), and the `crit*` note text color.
5. The crit swatch in the legend (same rule as item 4).

Accent is **not** used for links, stat values, headings, hover states, hit cells, or the threshold rule.

### Data colors: heat ramp and miss style (TABLE-02, D-08, D-09)

| Token | Light | Dark | Role |
|-------|-------|------|------|
| `--heat-lo` | `oklch(0.925 0.04 62)` #fbe1cc | `oklch(0.34 0.075 32)` #58271e | Ramp start (t = 0) |
| `--heat-hi` | `oklch(0.42 0.16 25)` #90101a | `oklch(0.70 0.17 27)` #f66d62 | Ramp end (t = 1), blood red |
| `--cell-ink-lo` | `oklch(0.20 0.03 40)` | `oklch(0.95 0.02 85)` | Hit-cell text when t < 0.5 |
| `--cell-ink-hi` | `oklch(1 0 0)` | `oklch(0.16 0.02 40)` | Hit-cell text when t ≥ 0.5 (class `.hi`) |
| `--ramp-a` / `--ramp-b` | 0.62 / 0.70 | 0.56 / 0.72 | Contrast dead-band skip (remap t → s) |
| `--miss-bg` | `oklch(0.87 0.006 80)` #d6d4d0 | `oklch(0.29 0.006 70)` #2d2b28 | Miss cell base (neutral grey-parchment) |
| `--miss-ink` | `oklch(0.45 0.01 80)` #58554f (5.0:1) | `oklch(0.72 0.01 70)` #a9a49e (5.7:1) | Muted `0` in miss cells |

- **Domain [default]:** `t = min(1, damage / heatMax)` with `heatMax = max(1, 2X + D)` (the crit-row maximum). Chosen so Phase 2 can pass one shared max for three tables (CMP-02). Normal hits sit on the lighter half; only the crit row reaches deep crimson. Accepted as honest (RESEARCH.md Pitfall 10, Open Question 3).
- **Ramp CSS (verbatim from RESEARCH.md Pattern 6):** `td.h` sets `--s: calc(var(--t) * 2 * var(--ramp-a))`; `td.h.hi` sets `--s: calc(var(--ramp-b) + (var(--t) - 0.5) * 2 * (1 - var(--ramp-b)))`; background `color-mix(in oklch, var(--heat-hi) calc(var(--s) * 100%), var(--heat-lo))`. JS emits only `style="--t:0.xxx"` and the `.hi` class; colors stay in CSS. Verified minimum cell-text contrast is 4.60:1 in both themes. The visible step at t = 0.5 coincides with the text flip and is intended.
- **Miss cells** (`td.m`, D-09): hatch `repeating-linear-gradient(135deg, var(--miss-bg) 0 4px, color-mix(in oklch, var(--miss-bg) 85%, var(--ink)) 4px 5px)`, text `0` in `--miss-ink`, weight 400. Differs from low hits by hue (neutral vs rose), texture (hatch), and muted text.
- **Cell class comes from `row.kind`, never from `damage === 0`.** A hit that deals 0 (damage penalty) is a `td.h` at t = 0 (pale rose, no hatch), not a miss.

### Status colors (self-test panel and error banner only) [default]

| Token | Light | Dark | Usage |
|-------|-------|------|-------|
| `--pass` | `oklch(0.45 0.11 145)` #26652b (5.9:1 on surface) | `oklch(0.78 0.13 145)` #80cd82 (8.5:1) | "passed" summary text and the 4px left border of the self-test panel when all pass |
| `--fail` | `oklch(0.47 0.17 27)` #a51f1e (6.2:1 on surface) | `oklch(0.74 0.15 27)` #fb8276 (6.6:1) | "FAILED" summary text, FAIL lines, left border of the self-test panel on failure and of the engine-failure banner |

Status is never color-only: every check line starts with the word `PASS` or `FAIL`, and the summary says "passed" or "FAILED".

## Layout Contract (D-01, D-02)

Single column, top to bottom, full width up to 1440px, page inline padding 16px, section gap 32px. **Not sticky. No side column at any width.**

```
[#selftest panel]            only when URL has ?test (hidden otherwise)
[#engine-error banner]       only if the engine or self-test crashed
<header>                     h1 + lede
<form#controls .strip>       Target AC | Damage die | Attack bonus | Damage bonus   (one row, wraps)
<section#stats>              6 stat cards (auto-fit grid) + full-width "Value of the next +1" card
<section#tables>             h2 "Outcome table" -> legend row -> .table-wrap > table -> crit footnote
<footer>
```

- **Control strip:** `--surface` background, 1px `--line` border, radius 8px, padding 16px 24px, `display: flex; flex-wrap: wrap; gap: 16px 24px; align-items: flex-end`. Each control group is a column: label line (Label 14/700 + range hint Small 12/400 muted, 4px apart) above the control, 8px gap. Labels sit above controls, never below (FEATURES.md, NN/g).
  - AC group: slider (192px, grows) and number input (80px) side by side, 8px gap, both `data-key="ac"`.
  - Die group: `<fieldset>` with `<legend>` "Damage die" styled as the group label; five radio inputs visually hidden (clip pattern, not `display:none`), each followed by a `<span>` segment 48×40. Segments are joined (no gap, shared 1px `--ink-muted` borders), outer corners radius 4px.
  - Attack bonus / Damage bonus: label above an 80px number input (1px `--ink-muted` border, radius 4px, `--paper` fill, centered tabular text).
  - On narrow viewports the groups wrap one per line and the AC slider takes the remaining width.
- **Stat cards:** grid `repeat(auto-fit, minmax(10rem, 1fr))`, gap 16px. Six across at ≥ ~1100px, wraps below. Card: `--surface`, 1px `--line`, radius 8px, padding 16px, three stacked lines with 8px gap: label (Label 14/400 muted) → value (Display 28/700 num, ink) → sub-line (Small 12/400 muted). Values never wrap (`white-space: nowrap`).
  - Focal point: the "Expected over 20 rounds" card (last in order) carries a 3px top border in `--ink`. It is the only card with it. It is the number every later phase compares against.
- **Marginal card** ("Value of the next +1"): spans the full grid row (`grid-column: 1 / -1`), same card style, h2 (Heading role), then two Body-size lines. The lead phrase (`+1 to hit:` / `+1 to damage:`) is 700; the numbers are num family 700.
- **Legend:** a single wrapping row between the h2 and the table (so Phase 2 can share one legend across three tables), `display: flex; flex-wrap: wrap; gap: 16px`, Label 14 text. Items in order: ramp strip (5 contiguous swatches) + text; miss swatch + text; crit swatch + text; threshold swatch + text. Swatches reuse the real `td.h`, `td.h.hi`, `td.m`, crit, and threshold classes so they cannot drift from the table.
- **Table section:** h2 → legend (16px below h2) → table (16px below legend, left-aligned) → footnote (Label 14, `--ink-muted`, max 72ch, 16px below table).
- **Footer:** Small 12 `--ink-muted`, 48px above, 1px `--line` top border, 16px padding-top.

## Interaction Contract (CTRL-01..03, CTRL-05)

| Control | Behavior |
|---------|----------|
| All controls | One delegated listener on `form#controls` for `input` (live) and `change` (commit). `submit` is `preventDefault`ed, so Enter never reloads. Every value goes through `VM.parseControl` (blank/NaN → previous value, out of range → clamp, rounded to integer). Renders are coalesced with `requestAnimationFrame`. |
| AC slider | min 10, max 30, step 1. Updates live while dragging. The number box mirrors it on the next frame. |
| AC number box | Typing updates live when the partial value parses. The box is **never rewritten while focused**, so "25" can be typed through "2". On `change` (blur/Enter) the box is normalized to the clamped state value (`99` → `30`, `''` → last valid). |
| Die segments | Radio group: one tab stop, arrow keys move the selection (native). Click or arrow key re-renders immediately. Listen to both `input` and `change`. |
| Attack / damage bonus | `<input type="number" min="-5" max="20" step="1">`. Native spin buttons and ArrowUp/ArrowDown step by 1. Same focus/normalize rule as the AC box. |
| Initial state | `init()` writes `{ac: 15, die: 8, atk: 5, dmg: 0}` into the controls, then renders synchronously once (D-03, D-04). The markup has no `value`/`checked` attributes. |
| Keyboard order | AC slider → AC number → die group → attack bonus → damage bonus. DOM order equals visual order. |
| Hover | Unchecked die segment only: background `color-mix(in oklch, var(--surface) 85%, var(--ink))`, `cursor: pointer`. Nothing else has a hover style. |
| Focus | `:focus-visible` ring per Accent item 1. For die segments the ring is drawn on the `span` via `input:focus-visible + span`. |
| Motion | None. No CSS transitions on cells, cards, or segments (a drag must not smear colors). No animation exists in Phase 1. |
| Invalid input | Silent clamp, no inline error text (ROADMAP success criterion 5). The table never shows a broken state. |

## States

| State | What the user sees |
|-------|--------------------|
| Default load | AC 15, d8, +5, +0. 20 × 8 table, threshold rule above row 10 (`hits on 10+`), stat cards `10+` / `55%` / `5%` / `4.91` / `2.700` / `54.0`, marginal `+0.225` and `+0.550` per round. |

| `?test` | `#selftest` panel above the header (see Self-test Panel). Normal loads keep it `hidden` (`[hidden] { display: none !important; }`) and only log to the console. |

## Self-test Panel (`?test`, RULES-08)

- `<section id="selftest" aria-label="Self-test results">`, `--surface`, radius 8px, 16px padding, 4px left border in `--pass` or `--fail`.
- Line 1 (Label 14/700): summary text in `--pass` or `--fail`.
- Line 2 (Small 12/400, muted): `Shown because the address contains ?test. Normal loads log these results to the browser console.`
- A `<details>` (open automatically when anything failed) with `<summary>` `Show all N checks`. Inside, one line per check in Small 12 num family: `PASS  {name}` or `FAIL  {name}: got {actual}, expected {expected}`. FAIL lines are `--fail`.
- Filled with `textContent` only. If the optional UI smoke test runs, its checks append to the same list after a line reading `UI checks`.

## Copywriting Contract

Numbers render in `--font-num` tabular. Signed values carry an explicit sign: `+5`, `+0`, `−2` (U+2212 MINUS SIGN in all display text; number inputs show the native `-2`). Use `×` (U+00D7), `÷`, and `≥`.

| Lede (Body) | `One attack roll, laid out as a table: a d20 to hit against Armor Class, then a damage die. Change the numbers and every outcome updates.` |
| Control labels | `Target AC` (hint `10 to 30`) · `Damage die` · `Attack bonus` (hint `−5 to +20`) · `Damage bonus` (hint `−5 to +20`) |
