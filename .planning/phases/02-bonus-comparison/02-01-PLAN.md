## Phase Goal

**As a** game designer, **I want to** pick a bonus N and see, cell by cell and as a curve, how +N on the attack roll compares with +N on the damage roll, **so that** I can see where the attack bonus plateaus and whether the two curves cross at all at the current AC and die.

<objective>
Deliver the first vertical slice of Phase 2: the "Compare at +N" slider and three compact outcome tables (Baseline, +N to hit, +N to damage), wired end to end through the one parser, one shared heat domain, per-table threshold rules and stats lines, and the three-up / stacked layout. Fix the four silent Phase 1 breakages this slice triggers.

Purpose: This is the cell-by-cell half of the lesson. A designer drags N and watches the threshold rule move up the +hit table while the +damage table's cells darken, all on one color scale.
Output: index.html with the compare section, the VM compare block, generalized table renderer, CSS; updated tools/check-engine.mjs and tools/check-page.mjs.

Out of scope for this plan (and phase): the 01-REVIEW WR-01 per-round precision fix (leave `perRoundText` untouched), any delta toggle, outlined new-hit rows, note-column or in-cell "+N" badges, and any GitHub push (local git only, user decision).
</objective>
