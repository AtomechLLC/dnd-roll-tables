# Phase 2 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> **This contract extends `01-UI-SPEC.md`.** Everything Phase 1 locks stays as it is: fonts, the 4-size / 2-weight type scale, spacing tokens `--sp-1..6`, surface/ink/accent tokens, heat ramp, miss style, table sizing tiers, legend classes, and focus ring. This file adds only what Phase 2 needs.
> Sources: 02-CONTEXT.md (D-01..D-18, locked), 02-RESEARCH.md (measured 1366 px layout, series tokens with computed contrast, niceTicks, crossing algorithm, reference values), 01-UI-SPEC.md, `index.html`. Values marked **[discretion]** were chosen here under CONTEXT.md "Claude's Discretion". Each has a one-line rationale.

## Design System

| Property | Value |
|----------|-------|
| Tool | none. Vanilla HTML/CSS/JS in one `index.html`. Not React, so the shadcn gate does not apply. |
| Preset | not applicable |
| Component library | none. Native `<input type="range">` + `<output>`, `<table>`, and inline `<svg>` built with `document.createElementNS` |
| Icon library | none. Text and Unicode only (`·`, `−`, `≥`, `×`). Legend line keys are tiny inline `<svg>` elements that reuse the chart's classes. No external requests (CSP `default-src 'none'`). |
| Font | Unchanged from Phase 1. `--font-prose` (Georgia stack) for words, `--font-num` (system-ui stack) + `font-variant-numeric: tabular-nums` for numbers. The same split applies inside the SVG. |
| Theming | Unchanged. The new tokens are defined on `:root` and overridden in the existing `@media (prefers-color-scheme: dark)` block. SVG colors come **only** from CSS class rules (`.series-hit { stroke: var(--series-hit) }`), never from `stroke="var(--x)"` presentation attributes (02-RESEARCH Pattern 4). |

| Item | Value | Rationale |
|------|-------|-----------|
| viewBox | `0 0 640 400`. CSS on the svg: `display:block; width:100%; height:auto; overflow:visible`. No `width`/`height` attributes. | D-09 says "about 640 × 360". A 16:10 box gives the plot 15% more height, so the plateau shape stays readable on a 328px phone (chart 205px tall instead of 185px). |
| Plot area | x 64 → 544 (480 wide, **24 units per N step**), y 32 (top) → 336 (bottom), 304 tall | Round step makes tick and hover math exact |
| Margins | left 64 (y tick labels), right 96 (direct labels), top 32 (band-label strip), bottom 64 (x tick labels + x title) | |
| Scales | `x = linearScale(0, 20, 64, 544)`; `y = linearScale(0, ticks.top, 336, 32)`, where `ticks = VM.niceTicks(max(attack[20], damage[20]) / den)` | y always starts at 0 (D-11) |
| Y gridlines | One per tick, x 64 → 544, 1 screen px `--line` | |
| X baseline | y = 336, x 64 → 544, 1 screen px `--ink-muted` | |
| X tick marks | Every integer N. y 336 → 340 (minor), 336 → 342 at multiples of 5. 1 screen px `--ink-muted` | D-11 |
| X tick labels | `+0 +5 +10 +15 +20` at y = 344, `dy="0.8em"`, `text-anchor: middle` | Signed labels match the "+N" naming everywhere else |
| Y tick labels | At x = 58, `text-anchor: end`, `dy="0.35em"`. Plain integers (`0`, `100`, `200`, `300`). niceTicks step is always ≥ 5 in the domain, so no decimals. | |
| X axis title | `Extra bonus +N`, centered at x = 304, y = 390 | D-11 (locked text) |
| Band rect | x from `x(b0)` to `x(b1)`, y 4 → 336. It spans the label strip and the plot, so the label sits inside the shading. | D-15 "in-band label" without the label ever touching a curve |
| Band label | x = `x(b0) + 4`, y = 24 (baseline), `text-anchor: start`. It may run past a narrow band's right edge. | 02-RESEARCH: a 1-step band still gets a readable label. Floor and cap labels can never collide, because capStart − floorEnd = 18 always. |
| Series | `<polyline>`, 21 points, **3 screen px** (`vector-effect: non-scaling-stroke`), `stroke-linejoin: round`, `fill: none`. To hit: solid. To damage: `stroke-dasharray: 8 4`. | 3px is in the Phase 1 stroke set (1/2/3). Dashing is the non-color cue (D-10). |
| N marker | Vertical line at `x(n)`, y 32 → 336, 2 screen px `--ink-muted`, solid. One dot on each curve at N (D-12). | |
| N marker dots | `r = 5` attribute. Fill is the series color. Stroke is 2 screen px `--paper` (halo) so the dot reads over the line. | |
| N marker label | `+N` (e.g. `+5`) in the x tick-label row at `x(n)`, same y/dy as the tick labels, weight 700, `--ink`. Regular tick labels with \|tick − N\| ≤ 1 are hidden, and at N = 5/10/15/20 the marker label replaces that tick's label. | The label strip above the plot belongs to the bands. The tick row can never collide with data. |
| Crossing marker | `<circle r="7">`, fill `--paper`, stroke 2 screen px `--ink`. Hollow, so it is distinct from the filled N dots. Placed at the interpolated `(x, yNum/den)` from `DiceMath.crossings` (on both drawn segments), or at the tied integer N. | D-14 |
| Crossing label | Centered on the marker x, baseline 20 units **below** the marker. If that goes below y = 330, it goes 12 units **above** instead. x is clamped so the text stays inside 64..544 (`text-anchor: end` at the right edge for an end tie). Drawn with a halo: `paint-order: stroke; stroke: var(--paper); stroke-width: 3px; stroke-linejoin: round`. | The halo keeps the label legible where it crosses a curve or the N marker |
| Direct labels | `to hit` / `to damage` at x = 552, `y = y(series[20])`, `dy="0.35em"`, weight 700, in the series color. De-collision: if the two y values are closer than **22 units**, push them apart symmetrically to 22 and clamp inside 32..336. | 22 = 1.25 × the largest font size at which the labels are shown (17.5), so the JS needs no layout reads (02-RESEARCH Pitfall 9) |
| Hover guide | Vertical line at `x(hoverN)`, y 32 → 336, 1 screen px `--ink-muted`, `stroke-dasharray: 2 3` (dotted). `hidden` when not hovering. | Thin and dotted, so it cannot be mistaken for the dashed damage series or the solid N marker |
| Hit target | `<rect class="hit" x="64" y="32" width="480" height="304" fill="none" pointer-events="all">`, first child (behind everything). Listeners go on the `<svg>`. `cursor: crosshair` on `.hit`. | 02-RESEARCH Pitfall 10 |

**Paint order (bottom → top):** hit rect → bands → y gridlines → x baseline + tick marks → N marker line → hover guide → damage polyline → to-hit polyline → N-marker dots → crossing markers → crossing labels → band labels → direct labels → tick labels + N marker label → x axis title.

**Exceptions:**
- Stroke widths are not spacing tokens: 1px (gridlines, ticks, baseline, hover guide), 2px (N marker, crossing ring, dot halo), 3px (series). These are the same stroke set Phase 1 declared.
- SVG user-unit values (font sizes 11.2/14/17.5/24, dot radii 5/7) scale with the viewBox. They are geometry, not spacing tokens. Their rendered sizes are pinned in Typography.
- Dash patterns `8 4` (damage series) and `2 3` (hover guide) are textures, like the Phase 1 miss hatch.

## Typography

**No new HTML type sizes or weights.** Phase 1 set: 12 / 14 / 16 / 28 px, weights 400 / 700.

| Role | Size | Weight | Line Height | Phase 2 elements |
|------|------|--------|-------------|------------------|
| Display | 28px | 700 | 1.2 | Not used in Phase 2 |
| Heading | 16px | 700 | 1.2 | The two new `h2`s (prose, small-caps, `letter-spacing: 0.04em`, existing rule) |
| Body | 16px | 400 / 700 | 1.5 | Section intro lines (prose 400). Chart caption `#chart-caption` (prose 400, `--ink`, max 72ch). Hover readout `#chart-readout` (num 400, tabular). N `<output>` value (num **700**). |
| Label | 14px | 400 / 700 | 1.4 | N control label `Compare at +N` (700) and hint (Small). Compact table titles in `<caption>` (**700**, `--ink`). Stats line under each compact table (400, with the total and delta in num 700). Chart legend text (400). Y-axis title above the chart (prose 400, `--ink`). |
| Small | 12px | 400 / 700 | 1.4 | N control hint `0 to 20`. Compact table cells and headers (existing mid/narrow tiers). |

**Chart text (one SVG role, sized in user units so it renders at 12–14 px).** CSS `font-size` on SVG `<text>` is in user units and scales with the viewBox (scale = chart width ÷ 640). The chart wrapper is a named container (`container: chart / inline-size`), and the font size steps by container width so the rendered size never drops below **12px** (Small) and sits at **14px** (Label) at full width. All SVG text uses this one size per tier:

| Tier | `chart` container width | SVG `font-size` (user units) | Rendered size | Direct labels | Dot `r` (CSS `r`, attribute fallback 5) |
|------|------------------------|------------------------------|---------------|---------------|------------------------------------------|
| full | ≥ 43rem (688px; the chart caps at 800px) | 11.2 | 12.0 – 14.0px | shown | 5 |
| medium | 35rem – < 43rem (560–687px) | 14 | 12.3 – 15.0px | shown | 6 |
| small | 28rem – < 35rem (448–559px) | 17.5 | 12.3 – 15.3px | shown | 7 |
| phone | < 28rem | 24 | 12.3px at 328px (360px viewport) | **hidden** (the HTML legend names the series) | 9 |

- Tier rules use named queries (`@container chart (width < 43rem)`) so they cannot be captured by a future wrapper (02-RESEARCH Pitfall 12). The crossing-marker radius steps the same way: 7 / 8 / 9 / 12.
- The in-between rendered sizes are scaling within the Label/Small band, not new type roles.
- SVG text families and weights: tick labels and the N marker label use `--font-num` tabular (400; marker label 700). The axis title uses `--font-prose` 400. Band labels use `--font-prose` italic 400, `--ink-muted`, matching the note-column labels. The crossing label uses `--font-prose` italic 700, `--ink`. Direct labels use `--font-prose` 700 in the series color.
- **Y-axis title lives in HTML [discretion]:** `<p class="chart-ytitle">Expected damage over 20 rounds</p>` sits directly above the SVG, left-aligned with the y tick labels, at Label 14 / 400 / `--ink`. Rationale: rotated SVG text collides with the y tick labels at the phone tier (24-unit font). A horizontal title above the axis stays readable at a fixed 14px at every width. The string is still in the DOM for the `--expect` check.

## Color

The Phase 1 60/30/10 split is unchanged. Phase 2 adds **three tokens**: two data-series colors and one band fill. Contrast values come from 02-RESEARCH (OKLab → sRGB, WCAG 2).

### Surface and ink (60 / 30 / 10), as used in Phase 2

| Role | Token | Phase 2 usage |
|------|-------|---------------|
| Dominant (60%) | `--paper` | Page and chart background (the SVG has no background fill), compact-table note column, dot halos, crossing-marker fill, label halos |
| Secondary (30%) | `--surface` | N control strip (`.strip`), compact-table header row and row-header column (existing rules), hover-readout panel |
| Accent (10%) | `--accent` | See the reserved list below. **The chart uses no accent.** |
| Destructive | — | None. Phase 2 has no destructive actions. |
| Text | `--ink` | Captions, stats lines, chart caption, readout, N marker label, crossing ring and label, y-axis title |
| Muted | `--ink-muted` | Section intros, N hint, tick marks, x baseline, tick labels, N marker line, hover guide, band labels |
| Hairline | `--line` | Y gridlines, readout panel border, band legend key border |

**Accent reserved for (exhaustive, Phase 1 list + one addition):**
1. Focus ring on every control (`:focus-visible`), including the N slider.
2. The checked die segment.
3. Range sliders: `accent-color: var(--accent)` on the AC slider **and the N slider** (the addition; both come from the shared `.pair input[type="range"]` rule).
4. The crit row (d20 = 20) bottom rule and `crit*` note text, in all four tables (inherited, not new).
5. The crit swatch in the legend.

Accent is **not** used for series lines, the N marker, crossing markers, bands, the readout, headings, or the `<output>` value.

### New data tokens [discretion; values from 02-RESEARCH "Series tokens"]

| Token | Light (parchment) | Dark (candlelit) | Contrast | Usage |
|-------|-------------------|------------------|----------|-------|
| `--series-hit` | `oklch(0.45 0.13 255)` (blue) | `oklch(0.78 0.10 245)` | Light 6.68:1 on paper, 6.20:1 on surface. Dark 9.16:1 / 8.22:1. | To-hit polyline (**solid**), its N-marker dot, its direct label, its legend key |
| `--series-dmg` | `oklch(0.47 0.12 50)` (burnt orange) | `oklch(0.78 0.13 55)` | Light 6.37:1 / 5.90:1. Dark 8.76:1 / 7.86:1. | To-damage polyline (**dashed `8 4`**), its N-marker dot, its direct label, its legend key |
| `--band` | `color-mix(in oklch, var(--ink) 8%, var(--paper))` | same formula (recomputes from the dark tokens) | 1.18:1 vs paper (light), 1.15:1 (dark). `--ink-muted` on it 5.65:1 (light), 7.31:1 (dark). Series on it ≥ 5.5:1. | Flat-stretch band rects and the band legend key |

- Both series pass 4.5:1 as text (direct labels) and far exceed 3:1 as graphics (WCAG 1.4.11) in both themes.
- Blue vs orange is the conventional color-blind-safe pair. Their lightness is similar (1.20:1 light, 1.04:1 dark), so **solid vs dashed plus the direct labels are the required non-color cues** (D-10). Hues stay clear of the heat ramp (25–32) and the amber accent (70–80).
- The band fill is low contrast by design. It is a region tint, and it is always identified by its in-band text label, never by fill alone.
- Mapping: **attack = solid blue** (the curve with the plateau), **damage = dashed orange** (the straight line).

### Heat domain (D-08, CMP-02)

- `heatMax = max over the three compact row sets` (the true maximum cell, equal to `max(1, 2X + D + N)`). It is computed once in the view and passed to **all four** tables and the single legend. The same number is the same color anywhere on the page.
- Intended consequence: at large N the Phase 1 study table uses only the paler half of the ramp (02-RESEARCH Pitfall 6). The `.hi` text flip keeps cell text ≥ 4.60:1 at every t, so nothing needs fixing.
- The default legend ramp labels change from `0 4 8 12 16` to **`0 5 11 16 21`** (N = +5, d8).

## Layout Contract (D-01, D-02, D-07, CMP-05)

Page order (the Phase 1 sections are untouched, and the new sections go after `#tables`, before `</main>`):

```
<form#controls .strip>      (Phase 1, unchanged)
<section#stats>             (Phase 1, unchanged)
<section#tables>            h2 "Outcome table" -> legend -> big table (wide tier) -> crit footnote   (unchanged)
<section#compare>           container "compare" / inline-size
    h2#compare-h
    p.section-intro
    form#compare-controls.strip.n-strip     (one .group: label + .pair[range + output])
    div.trio                               (grid: 1 column, or 3 at >= 77rem)
        div.cmp  x3  (order: base, hit, dmg)
            div.table-wrap > table.outcome#cmp-{base|hit|dmg}   (caption = title)
            p.cmp-stats#cmp-{base|hit|dmg}-stats
<section#chart>
    h2#chart-h
    p.section-intro
    div.chart-wrap          container "chart" / inline-size; max-width 50rem
        div.legend.chart-legend
        p.chart-ytitle
        div.plot            touch-action: pan-y
            svg#sweep  viewBox="0 0 640 400" role="img" aria-labelledby="chart-caption" focusable="false"
        p#chart-readout.readout
        p#chart-caption.chart-caption
<footer>                    (unchanged)
```

**Compare section**
- `h2` (existing rule, 16px below) → intro (Label 14 / 400 / `--ink-muted`, max 72ch, `margin: 0 0 var(--sp-3)`) → N strip → 24px → `.trio`.
- **N strip [discretion]:** reuses `.strip` (surface, 1px line border, radius 8px, padding 16px 24px) with `width: fit-content; max-width: 100%`. One `.group` holds a label line (`Compare at +N` 14/700 + hint `0 to 20` 12/400 muted, same markup as the AC label) above a `.pair` with the range and the `<output>`. Rationale: the same affordance as the top strip, so it reads as a control, not decoration.
- `<output id="n-out" for="n-range">`: Body 16 / 700 / `--font-num` tabular, `min-width: 48px`, `height: 40px`, `line-height: 40px`, centered, no border. Shows `+5`.
- `.trio`: `display: grid; grid-template-columns: minmax(0, 1fr); gap: var(--sp-4) var(--sp-3);`. At `@container compare (width >= 77rem)`: `repeat(3, minmax(0, 1fr))`. It never lays out as 2 + 1.
- `.trio .table-wrap { max-width: calc(42rem - 1px); }` keeps the compact tables in the mid tier (or narrow below 25rem) even when stacked full width, so they never become three more copies of the 652px study table.
- Retarget every `#outcome` selector to `.outcome`, and add `class="outcome"` to the Phase 1 table. The Phase 1 table must render pixel-identically (02-RESEARCH Pattern 2 checked specificity).
- Measured budget (02-RESEARCH Pattern 5): a 1366px window gives a 1297px content box, so three tracks at 16px gap are 421.7px each, holding a 400px d12 table with 21px to spare. At 1280px the grid stacks (expected, and not a defect). At 360px the tables stack at the 328px narrow tier. There is never horizontal page scroll.
- Compact table `<caption>`: `caption-side: top`, left, **Label 14 / 700 / `--ink`**, 8px below (override of the Phase 1 muted 400 caption, scoped to `.trio caption`). Visible text is the title only. A `.vh` span appends the full description for assistive tech (see Copywriting).
- `.cmp-stats`: `margin: var(--sp-2) 0 0`, Label 14 / 400 / `--ink`, numbers in `--font-num` tabular. The 20-round total and the delta are wrapped in `<b class="num">` (700). The table gets `aria-describedby` pointing at its stats line.

**Chart section**
- `h2` → intro (same style as the Compare intro) → `.chart-wrap`.
- `.chart-wrap`: `container: chart / inline-size; max-width: 50rem;`, left-aligned.
- Chart legend: reuses `.legend` and `.legend-item` (flex wrap, 16px gap, padding-block 8px, 16px bottom margin, Label 14). The five items are listed in Copywriting.
- `.chart-ytitle`: `margin: 0 0 var(--sp-1)`, Label 14 / 400 / prose / `--ink`.
- `.plot`: `touch-action: pan-y`. Vertical page scroll still works, and a horizontal drag scrubs the readout.
- `.readout`: `margin: var(--sp-2) 0 0; padding: var(--sp-2) var(--sp-3); background: var(--surface); border: 1px solid var(--line); border-radius: 8px;` Body 16 / 400 / `--font-num` tabular / `--ink`. `min-height` is one line box (`calc(1.5em + 18px)`) at ≥ 35rem and two line boxes (`calc(3em + 18px)`) at `@container chart (width < 35rem)`, so hovering never shifts the page.
- `.chart-caption`: `margin: var(--sp-3) 0 0; max-width: 72ch;` Body 16 / 400 / prose / `--ink`.

## Component Contract: Compact Comparison Tables (CMP-01..05, D-04, D-06..D-08, D-17)

| Part | Spec |
|------|------|
| Renderer | The one generalized table renderer (D-17) writes all four tables. | Corner | `d20` (the mid/narrow tier hides the ` \ dX` part, existing rule) |
| Hover / tooltips | None |

## Interaction Contract (CTRL-04)

| Control / surface | Behavior |
|-------------------|----------|
| N slider | `<input type="range" id="n-range" data-key="n" step="1">`. `min`/`max` are set from `VM.CONTROL_SPEC.n` in `init()` (0..20; no fifth copy of the domain, IN-04). It updates live on `input`. Every value goes through `VM.parseControl('n', …)`. |
| Control root | `form#compare-controls` is a **second control root**: the same `submit` preventDefault plus `input` / `change` delegation as `#controls`. `renderControls` walks `document.querySelectorAll('[data-key]')` and writes `VM.signed(state.n)` into `#n-out` (02-RESEARCH Pattern 1). |
| Initial state | `DEFAULT_STATE.n = 5`. First load shows `+5`. Markup carries no `value` attribute. |

## Copywriting Contract

Phase 1 conventions hold: U+2212 minus in display text, `·` separators, signed values via `VM.signed` (`+5`, `+0`, `−2`), and one-decimal 20-round figures via `VM.fixed(tenths, 1)`. **Naming [discretion]:** the two variants are always called `+N to hit` and `+N to damage` (or, with a number, `+5 to hit` / `+5 to damage`), and the direct labels shorten them to `to hit` / `to damage`. One name each, everywhere: tables, legend, readout, caption.

| Element | Copy |

**Chart caption `#chart-caption` (generated in `VM.chartView`; this is the SVG's accessible name).** Sentences are joined with a single space.

1. **Setup (always):** `Expected damage over 20 rounds at AC 15, d8, attack +5, damage +0. Both curves start at 54.0 with no extra bonus.`
2. **Order (always):** build runs of equal sign of (to hit − to damage) over N = +1..+20. Leader phrases: positive → `+N to hit leads`, negative → `+N to damage leads`, zero → `the two are even` (capitalize `The` when it opens the sentence). Range phrase: a single run covering all of +1..+20 → `at every N from +1 to +20`; a one-step run → `at +a`; otherwise `from +a to +b`. Join runs with `, then `, and end with `.`.
3. **Crossing count (always):** 0 crossings and no ties → `The curves never cross.` 0 crossings with a tie → `The curves meet at +T but do not cross.` 1 → `The curves cross once.` (a tie crossing adds `, at +T` before the period). 2 → `The curves cross twice.` k ≥ 3 → `The curves cross k times.`
4. **Bands (only when drawn):** cap only → `Shaded from +8 to +20: the 95% cap, where more to-hit adds nothing.` Floor only → `Shaded from +0 to +5: only a nat 20 hits, so more to-hit adds nothing yet.` Both → both sentences, floor first.

| Case | Sentences 2 + 3 (exact) |

| Tie crossing (AC 10 / +0 / d4 / +14) | `+N to hit leads from +1 to +11, then the two are even at +12, then +N to damage leads from +13 to +20. The curves cross once, at +12.` |
| End tie (AC 27 / −5 / d4 / +0) | `+N to damage leads from +1 to +19, then the two are even at +20. The curves meet at +20 but do not cross.` |
