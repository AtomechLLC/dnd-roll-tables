## Phase Goal

**As a** game designer, **I want to** roll 20 real rounds at the current settings and compare the realized total with the exact expectation and its spread, **so that** I learn not to over-trust averages while the exact and simulated numbers never blur together.

<objective>
Second slice: after a roll, the designer sees every round (d20, result, the real damage dice, damage) in a 20-row log whose total equals the figure. When they change the attack afterwards, the old run dims, states the settings it was rolled at, and shows a "Now:" line for the current settings, without re-rolling and without flicker while dragging. Repeated clicks at the same settings build a tally of the last 5 totals.

Purpose: This completes SIM-03 and SIM-04. The designer can trace exactly where a total came from, and a stale run can never be mistaken for the current settings.
Output: index.html (renderSim extension, log and stale CSS, UI smoke block), tools/check-page.mjs (header comment).

Out of scope: marks on the #outcome table and the legend item (plan 03-03). No push.
</objective>

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-03-07 | Tampering (HTML injection) | log tbody / tfoot innerHTML | mitigate | Only integers coerced with `| 0` and words from a fixed lookup table (hit / miss / crit, '—', ' + ') reach innerHTML. The non-comment `.innerHTML =` count is pinned at 4 by a grep gate. |
| T-03-08 | Tampering | note, Now:, tally, caption | mitigate | Built with textContent / createElement / replaceChildren from VM.settingsText (clamped integers through signed()). |
| T-03-09 | Repudiation / integrity | stale run shown as current | mitigate | Staleness is recomputed every frame from a frozen params copy (Sim.sameAttack). The exact card keeps the rolled-at figure beside the rolled total, and the smoke asserts stale and un-stale transitions for all four attack controls and none for N. |
| T-03-10 | Denial of service | tally growth, repeated clicks | accept | The tally is capped at 5 (smoke-checked). Each roll is O(20), and the log is rebuilt once per click. |

This plan installs no packages, so the supply-chain threat does not apply.
