## Phase Goal

**As a** game designer, **I want to** roll 20 real rounds at the current settings and compare the realized total with the exact expectation and its spread, **so that** I learn not to over-trust averages while the exact and simulated numbers never blur together.

<objective>
Final slice: the run shows up on the big outcome table itself. Rolled hit cells get rings with repeat badges, and crit, miss, and nat 1 rows get counted row labels. The marks clear when the attack changes and return when it changes back. Then verify the whole phase against the ROADMAP success criteria and the UI-SPEC states.

Purpose: The designer sees which outcomes of the 20 × X space one fight actually landed on, which ties the random run back to the exact table. The verification pass proves every Phase 3 criterion with checks and screenshots.
Output: index.html (marks rendering, CSS, legend item, UI smoke), 03-03-SUMMARY.md with the success-criteria and decision mapping.

Out of scope: marks on the compact tables, a cell mark for crits (D-12 forbids it), tooltips or click actions on marks, and any push. Note: D-11 brings the v2 idea INT-02 (rolled cells highlighted on the table) into this phase by user decision, in exactly the form D-11 to D-13 specify.
</objective>
